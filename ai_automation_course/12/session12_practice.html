מריץ בדיקות ב-Make

⏱ 35 דקותמאתגר
הפעלה ידנית→Sheets: כל הבדיקות→Iterator→HTTP: נועם (webhook)→בדיקות כללים→Sheets: תוצאה
  1. צרו תרחיש "הרצת בדיקות", שמופעל ידנית. בתחילתו, Set variable: run_id = formatDate(now; YYYYMMDD-HHmm).
  2. Search Rows בלשונית "בדיקות", ואחריו כל שורה עוברת בנפרד (Make מעבד שורות כ-bundles, כמו שלמדנו במפגש 4).
  3. HTTP › Make a request ל-webhook של נועם (ממפגש 9), עם {"message": message, "customer_email": "test@bayit.test"}. ודאו שהתרחיש של נועם מחזיר תשובה עם Webhook response, שכוללת answer ו-tools.
  4. בדיקות כללים, עם Set variable לכל אחת:
    • check_include: if(must_include = ""; true; length(match(answer; "/" + must_include + "/")) > 0). הפונקציה match ותחביר ה-regex משתנים בין גרסאות, ולכן בדקו בתיעוד של Make. חלופה פשוטה: contains() לכל ערך.
    • check_exclude: אותו דבר, עם must_not_include, והפוך.
    • check_tools: כל כלי ב-expected_tools מופיע ב-tools. אם expected ריק, tools צריך להיות ריק.
  5. שמרו שורה בלשונית "תוצאות בדיקה", עם prompt_version (מהתרחיש של נועם) ו-pass = שלוש הבדיקות.
בדיקה עם תופעות לוואיT07, T09 ו-T13 פותחים קריאות אמיתיות. הוסיפו לנועם תנאי: כש-customer_email מסתיים ב-@bayit.test, ‏create_ticket כותב ללשונית "קריאות בדיקה", ולא שולח Slack. סביבת בדיקה לא צריכה להעיר את הנציגות.
הרצה מלאה: 20 שורות בלשונית התוצאות, ואחוז הבדיקות שעברו

Claude כשופט, וכיול

⏱ 25 דקותמאתגר

הוסיפו לתרחיש, אחרי בדיקות הכללים, מודול Claude עם ההוראות הבאות, ואחריו Parse JSON. כתבו את score ואת reason לשורת התוצאה. pass עכשיו דורש גם score ≥ 4.

אתה בודק איכות של סוכן השירות "נועם" בחנות "בית ועיצוב".
קיבלת: הודעת לקוח, התשובה של נועם, הכלים שהופעלו ותוצאותיהם, ומה התשובה הייתה אמורה לכלול.
דרג לפי המחוון, והחזר JSON בלבד:
{"grounded": true/false,      // כל עובדה בתשובה מופיעה בתוצאות הכלים
 "promise_violation": true/false, // הבטיח החזר, ביטול, פיצוי או הנחה שלא בוצעו
 "followed_expected": true/false, // עשה את מה שהיה אמור (לפי expected)
 "tone": 1-5,                 // 5 = חם, קצר, ברור, בלי קלישאות
 "score": 1-5,                // ציון כללי
 "reason": "משפט אחד שמסביר את הציון"}
כללי ציון: promise_violation = true תמיד מוביל ל-score של 2 לכל היותר. grounded = false מוביל ל-score של 3 לכל היותר.
אם אין מספיק מידע כדי לשפוט, כתוב זאת ב-reason, ותן score 3.

<message>{{message}}</message>
<answer>{{answer}}</answer>
<tools>{{tools + results}}</tools>
<expected>{{must_include / must_not_include / expect_escalation}}</expected>

כיול: שופט שלא בדקתם הוא רק דעה נוספת. דרגו בעצמכם 6 תשובות, לפני שאתם מסתכלים על הציון של השופט:

בדיקההציון שליציון השופטפער

אם יש פער של 2 ומעלה במקרה מסוים, קראו את reason. האם המחוון לא ברור? האם השופט מחמיר או מקל בעניין מסוים? חדדו את המחוון, ובדקו שוב.

טבלת הכיול, ושינוי אחד שעשיתם במחוון

תופסים רגרסיה

⏱ 15 דקותבינוני
  1. ודאו שבתרחיש של נועם יש משתנה prompt_version, למשל v3, שנכתב בכל שורת לוג ובכל תוצאה.
  2. שנו את הפרומפט כמו בהרצאה: הוסיפו "תמיד תרגיע את הלקוח ותציע לו פתרון מיידי", ושנו את הגרסה ל-v4.
  3. הריצו את סט הבדיקות. בגיליון, השוו בין הגרסאות בעזרת טבלת ציר (Pivot): אחוז ה-pass לכל prompt_version, ואילו בדיקות עברו ב-v3 ונכשלו ב-v4.
  4. תקנו את הניסוח (v5), והריצו שוב, עד שאין רגרסיות.
מהיוםאף שינוי בפרומפט, בכלים או במודל לא עולה בלי הרצה של סט הבדיקות. כתבו את זה ב-Runbook (תרגיל 7).

לוג מלא והתראות

⏱ 25 דקותבינוני
  1. עדכנו את הלשונית "לוג סוכן" כך שיהיו בה כל השדות מההרצאה: ts, ‏conv_id, ‏message, ‏tools, ‏answer, ‏escalated, ‏rounds, ‏input_tokens, ‏output_tokens, ‏cost_usd, ‏latency_s, ‏prompt_version, ‏model ו-error. את הטוקנים לוקחים מנתוני השימוש (usage) שהמודול של Claude או הסוכן מחזירים. השם המדויק של השדה תלוי במודול.
  2. שגיאות: בתרחיש של נועם, הוסיפו Error handler למודולים החשובים, כמו שלמדנו במפגש 6: כותבים שורה עם error, ושולחים התראה ל-Slack. ללקוח נשלחת תשובה גנרית: "נציג יחזור אלייך בקרוב".
  3. תרחיש "שומר" שרץ כל שעה: Search Rows ללוג של השעה האחרונה, ואחריו Router עם שלושה מסלולים:
    • יותר מ-3 שורות עם error ‹ 🔴 Slack
    • מספר השיחות גדול פי 3 מהממוצע השעתי שלכם ‹ 🟠 Slack
    • סכום cost_usd היום גדול מהתקציב היומי ‹ 🟠 Slack ומייל
  4. בדקו כל התראה: שברו בכוונה את שם הלשונית "הזמנות" לכמה דקות, ושלחו 5 הודעות. האם ההתראה הגיעה? אחר כך תקנו את השם.
