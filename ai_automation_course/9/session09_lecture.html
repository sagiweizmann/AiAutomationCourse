חלק 1 · Workflow או סוכן

מי מחליט מה קורה עכשיו?

עד היום, אתם קבעתם את הסדר: מודול אחרי מודול, ו-Claude עשה משימה אחת בכל שלב. בסוכן (Agent), Claude מקבל מטרה ורשימת כלים, ומחליט בעצמו באיזה כלי להשתמש, באיזה סדר, ומתי לעצור. זה לא "כן או לא". זה רצף, וכדאי לבחור את הנקודה הפשוטה ביותר שעושה את העבודה.

חלק 2 · לולאת הסוכן

מה קורה בתוך סוכן

סוכן הוא לולאה פשוטה. Claude מקבל את ההודעה ואת רשימת הכלים, ומחליט: לענות, או לבקש להפעיל כלי. אם הוא מבקש כלי, המערכת שלכם (Make, או קוד) מפעילה אותו ומחזירה את התוצאה. Claude ממשיך מאותה נקודה, עד שהוא עונה. Claude עצמו לא נוגע במערכות: הוא רק מבקש, ואתם מחליטים מה באמת קורה.

אנימציה

סוכן השירות "נועם" בפעולה

מה רואים מבחוץ
מה עובר ב-API (Messages API)

      

    

  

  
שני שדות שכדאי להכירכש-Claude רוצה כלי, התשובה מגיעה עם stop_reason: "tool_use", ובתוכה בלוק tool_use עם שם הכלי והקלט. אתם מחזירים בלוק tool_result עם אותו id. כשהוא מסיים, stop_reason הוא "end_turn". פלטפורמות כמו Make AI Agents מריצות את הלולאה הזו בשבילכם, אבל זה מה שקורה מתחת למכסה.






  
חלק 2 · הגדרת כלי

  
האנטומיה של כלי

  
Claude לא רואה את הקוד של הכלי, ולא את התרחיש ב-Make. הוא רואה רק שם, תיאור וסכמת קלט. מתוך שלושת אלה הוא מחליט אם להשתמש בכלי ומה להעביר לו. לכן התיאור הוא החלק הכי חשוב: הוא בעצם פרומפט.

  

    
{
  "name": "get_order_status",
  "description": "Returns status and details of ONE order by its 4-digit order number: items, amount, status, order date, ETA and notes. Use for any question about a specific order. If the customer gave no order number, ask for it first.",
  "input_schema": {
    "type": "object",
    "properties": {
      "order_id": {
        "type": "string",
        "description": "4-digit order number, e.g. 1043"
      }
    },
    "required": ["order_id"]
  }
}

    
    
      
  1. name: פעולה ברורה באנגלית, עם קו תחתון. get_order_status עדיף על tool1.
    2. 
      
  2. description: מה הכלי מחזיר, מתי להשתמש בו, ומתי לא. כאן נמצאים רוב הבאגים של סוכנים.
    3. 
      
  3. input_schema: סכמת JSON. מגדירה סוגים, ערכים מותרים (enum) ושדות חובה, ומונעת קלט לא תקין.
    4. 
      
  4. אפשר לכתוב את התיאור גם בעברית. רוב הדוגמאות באנגלית, וזה עובד טוב בשתי השפות. העיקר שיהיה מדויק.
    5. 
    

  


  

    
מעבדה
תיאור טוב או תיאור עצלן?

    

      
החליפו בין תיאור "עצלן" לתיאור "מדויק" לכל אחד משלושת הכלים, וראו איך הסוכן מתנהג בארבע הודעות בדיקה.

      

      

      

    

  






  
חלק 3 · הרשאות

  
גבולות לסוכן: מה מותר לו לעשות לבד

  
סוכן שקורא מידע הוא כמעט לא מסוכן. סוכן שכותב, שולח או מחזיר כסף הוא סיפור אחר. הזרקת פרומפט (Prompt injection) היא טקסט שמגיע בתוך המידע, כמו מייל, הערה בהזמנה או דף אינטרנט, ומנסה לתת לסוכן הוראות. Claude מאומן לזהות ניסיונות כאלה, אבל שום מודל לא חסין לגמרי. ההגנה החשובה ביותר היא לא בפרומפט, אלא בהרשאות: גם אם הסוכן "השתכנע", מה הוא בכלל מסוגל לעשות?
