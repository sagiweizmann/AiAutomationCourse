RAG-lite ב-Make

⏱ 35 דקותמאתגר
Webhook (question)→Claude: נושא→Sheets · Search Rows (topic)→Text aggregator→Claude: תשובה עם מקורות→Parse JSON→Sheets · לוג
  1. צרו תרחיש "שאלות ידע", שמתחיל ב-Custom webhook שמקבל {"question": "..."}.
  2. Claude 1 (סיווג): מודל קטן, עם ההוראות שבהמשך. אחריו Parse JSON.
  3. Google Sheets ‹ Search Rows בלשונית "ידע", עם התנאי topic = הנושא שחזר מ-Claude. הגבילו ל-10 תוצאות.
  4. Tools ‹ Text aggregator: בשדה Source module בחרו את Search Rows. בשדה Text כתבו: [id] (source) content, עם מיפוי. בשדה Row separator בחרו New row.
  5. Claude 2 (תשובה): מודל בינוני, עם ההוראות שבהמשך. בהודעה של המשתמש: השאלה. אחריו Parse JSON.
  6. שמרו בלשונית "לוג שאלות": שאלה, נושא, תשובה, cited_ids, answerable ותאריך.
Claude 1, הוראות מערכת: 
סווג את שאלת הלקוח לנושא אחד מהרשימה:
shipping, returns, defect, warranty, contact, product, payments, general
החזר JSON בלבד: {"topic": "...", "product_hint": "שם מוצר אם הוזכר, אחרת null"}
Claude 2, הוראות מערכת: 
אתה עוזר השירות של "בית ועיצוב". ענה על שאלת הלקוח רק לפי קטעי הידע שבתוך <context>.
החזר JSON בלבד:
{"answer": "תשובה בעברית, עד 70 מילים", "cited_ids": ["KB-.."], "answerable": true/false}
- כל עובדה בתשובה חייבת להופיע בקטעים, ואת ה-id שלה כותבים ב-cited_ids.
- אם אין בקטעים מספיק מידע: answerable = false, ו-answer = "אבדוק ואחזור אלייך".

<context>
{{טקסט מה-Text aggregator}}
</context>
מה עושים עם שאלה על מוצר?כש-topic = product, אפשר לחפש לפי title שמכיל את product_hint, במקום לפי topic. כך נשלפת רק השורה של המוצר הרלוונטי.
