חלק 1 · JSON

JSON: נתונים שגם אדם וגם מכונה יכולים לקרוא

JSON בנוי מזוגות של מפתח: ערך. ערך יכול להיות טקסט, מספר, אמת או שקר, ריק (null), אובייקט (סוגריים מסולסלים) או מערך, כלומר רשימה (סוגריים מרובעים). ב-Make מגיעים לכל ערך לפי הנתיב שלו. לחצו על מפתח כדי לראות את הנתיב שלו.

חלק 2 · API

API: מלצר בין שתי מערכות

API הוא הדרך המוסדרת שבה מערכת אחת מבקשת משהו ממערכת אחרת. כמו במסעדה, הלקוח (Make) לא נכנס למטבח (מסד הנתונים). הוא מוסר הזמנה למלצר (ה-API), והמלצר חוזר עם מנה (התשובה). כל בקשה כוללת שיטה, כתובת, כותרות (Headers) ולפעמים גם גוף (Body).

🎫 OAuth

המשתמש מאשר לאפליקציה גישה מוגבלת לחשבון שלו, בלי למסור לה את הסיסמה. זה כמו מפתח שירות שמקבל החניון: מתניע את הרכב, אבל לא פותח את תא המטען. כך Make מתחבר ל-Gmail או ל-Google Sheets.

חלק 3 · Webhooks

"יש משהו חדש?" מול "אני אודיע לך"

יש שתי דרכים לדעת שקרה משהו חדש. Polling: שואלים את המערכת שוב ושוב אם יש משהו חדש. Webhook: המערכת שולחת הודעה לכתובת שלנו ברגע שמשהו קורה. הפעילו את שתי הדרכים ותראו את ההבדל.

חלק 3 · Claude API

הקריאה הראשונה ל-Claude

במפגש 1 עבדנו עם Claude בצ'אט. דרך ה-API, Make (או כל מערכת אחרת) שולח ל-Claude בקשה ומקבל תשובה בפורמט JSON, בלי שאדם יושב מול המסך. ערכו את השדות, צפו בבקשה שנבנית, ושלחו.

בונה בקשות ל-Claude API

לחצו "שליחה"
הנתיב שחשוב לזכורהטקסט ש-Claude כתב נמצא ב-content[0].text. זה השדה שנמפה ב-Make במפגשים הבאים. ב-usage רואים כמה טוקנים נכנסו ויצאו, ולפיהם משלמים.
שימו לבהסימולציה מדמה את מבנה הבקשה והתשובה. בתרגול תשלחו בקשה אמיתית מ-Postman. את שם המודל ואת גרסת ה-API (הכותרת anthropic-version) בודקים בתיעוד העדכני של Anthropic.
