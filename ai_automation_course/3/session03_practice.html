לפניכם הזמנה בפורמט JSON. כתבו את הנתיב לכל אחד מששת הנתונים, בפורמט שבהרצאה (למשל customer.name).

{
  "order_id": 50912,
  "customer": {
    "name": "רונית שגב",
    "contact": { "phone": "054-2223344", "email": "ronit@example.com" }
  },
  "items": [
    { "sku": "BAR-01", "name": "כיסא בר", "qty": 3, "price": 390 }
  ],
  "shipping": { "method": "express", "eta_days": 3, "tracking": null },
  "tags": ["vip", "repeat"]

  1. הטלפון של הלקוחה
  2. שם המוצר הראשון
  3. כמות היחידות של המוצר הראשון
  4. שיטת המשלוח
  5. התגית השנייה
  6. מספר המעקב, ומה הסוג של הערך שלו

בקשות GET ראשונות ב-Postman

⏱ 20 דקותקל
  1. פתחו את Postman (אפליקציה או גרסת דפדפן), ולחצו New ‹ HTTP.
  2. שלחו את שלוש הבקשות שבהמשך. JSONPlaceholder הוא שירות ציבורי לתרגול שמחזיר נתוני דוגמה.
  3. לכל בקשה רשמו: קוד הסטטוס, האם התשובה היא אובייקט או מערך, וכמה רשומות הגיעו.
GEThttps://jsonplaceholder.typicode.com/users/1
GEThttps://jsonplaceholder.typicode.com/users
GEThttps://jsonplaceholder.typicode.com/posts?userId=1

שאלות: (א) מה שם החברה של משתמש 1, ומה הנתיב לשדה הזה? (ב) מה ההבדל בין התשובה של הבקשה הראשונה לתשובה של השנייה? (ג) מה עושה ?userId=1 בכתובת?

טבלה: בקשה · סטטוס · אובייקט/מערך · מספר רשומות, ותשובות לשאלות א-ג
4

POST, כותרות וקודי שגיאה

⏱ 20 דקותבינוני

חלק א': צרו ליד חדש. בחרו בשיטה POST, ובלשונית Body ‹ raw ‹ JSON הדביקו את גוף הבקשה:

POSThttps://jsonplaceholder.typicode.com/posts
{
  "title": "ליד חדש: נועה כהן",
  "body": "מתעניינת בשולחן אלון",
  "userId": 1
}

איזה קוד סטטוס קיבלתם? איזה שדה חדש הופיע בתשובה?

חלק ב': httpbin מחזיר לכם בדיוק את מה ששלחתם. שלחו POST עם אותו גוף, והוסיפו בלשונית Headers כותרת x-api-key עם ערך כלשהו (לא אמיתי!):

POSThttps://httpbin.org/post

חלק ג': שלחו את שלוש הבקשות האלה ורשמו מה כל קוד אומר, ומה אוטומציה צריכה לעשות כשהיא מקבלת אותו:

GEThttps://jsonplaceholder.typicode.com/users/999
GEThttps://httpbin.org/status/401
GEThttps://httpbin.org/status/429
קודי הסטטוס של חלקים א'-ג', ולכל קוד שגיאה: מה הוא אומר ומה האוטומציה צריכה לעשות

ה-Webhook הראשון שלכם

⏱ 20 דקותבינוני
  1. היכנסו ל-webhook.site. האתר נותן לכם כתובת ייחודית (Your unique URL). העתיקו אותה.
  2. ב-Postman שלחו POST לכתובת הזו, עם גוף הליד שבהמשך. כך מדמים טופס באתר ששולח ליד.
  3. חזרו ל-webhook.site וראו את הבקשה שהגיעה: מתי היא הגיעה, אילו כותרות היו בה, ומה הגוף שלה.
  4. שלחו עוד שני לידים עם שמות אחרים, ושימו לב שכל אחד מהם מגיע מיד.
{
  "full_name": "נועה כהן",
  "email": "noa@example.com",
  "phone": "050-1112233",
  "interested_in": "שולחן אלון",
  "source": "website",
  "message": "האם השולחן זמין בצבע אגוז?"
}
למה זה חשובבמפגש הבא Make יקבל כתובת Webhook משלו, בדיוק כמו ב-webhook.site. כל ליד שיישלח לכתובת הזו יפעיל את התהליך.
צילום מסך מ-webhook.site עם 3 לידים, ותשובה לשאלה: מה ההבדל בין זה לבין Polling?

קריאה ראשונה ל-Claude API

⏱ 30 דקותמאתגר
  1. היכנסו ל-Claude Console (console.anthropic.com). תחת API Keys צרו מפתח חדש בשם "course". העתיקו אותו ושמרו במקום בטוח, כי לא תוכלו לראות אותו שוב.
  2. הגדירו מגבלת הוצאה (Spend limit) נמוכה בחשבון, כדי שלא יהיו הפתעות.
  3. ב-Postman צרו Environment בשם "Course", עם משתנה CLAUDE_API_KEY מסוג secret, והכניסו אליו את המפתח. כך המפתח לא מופיע בבקשה עצמה.
  4. צרו בקשה חדשה עם הפרטים שבהמשך, ושלחו אותה.
POSThttps://api.anthropic.com/v1/messages
HeaderValue
x-api-key{{CLAUDE_API_KEY}}
anthropic-version2023-06-01
content-typeapplication/json
{
  "model": "claude-sonnet-5-5",
  "max_tokens": 300,
  "system": "אתה מחלץ נתונים מפניות לקוחות של חנות 'בית ועיצוב'. החזר JSON בלבד, בלי טקסט נוסף, עם השדות: customer_name, order_id, topic (delivery | defect | product_question | other), urgency (low | medium | high).",
  "messages": [
    {
      "role": "user",
      "content": "זו הפעם השלישית שאני פונה!!! הזמנתי 3 כיסאות בר (הזמנה 50912) לפני חודש ושום דבר. רונית שגב"
    }
  ]
}
שם המודלאת שם המודל המדויק העתיקו מעמוד המודלים בתיעוד של Anthropic. השם בדוגמה עלול להשתנות. אם קיבלתם שגיאה 404 עם הודעה על המודל, זו כנראה הסיבה.

אחרי שקיבלתם תשובה: (א) מה הנתיב לטקסט ש-Claude כתב? (ב) כמה טוקנים נכנסו וכמה יצאו? (ג) שנו את ההודעה למייל של אבי מזרחי ממפגש 1 ושלחו שוב. האם המבנה נשאר זהה?

קיבלתי שגיאה401: בדקו שהמפתח נכון ושה-Environment "Course" נבחר בפינה של Postman. 400: בדקו שה-JSON בגוף הבקשה תקין. 404: בדקו את שם המודל ואת הכתובת.
צילום מסך של הבקשה והתשובה, כשהמפתח מוסתר, ותשובות ל-א'-ג'

בונוס: Claude כמתרגם תיעוד

⏱ 10 דקותבונוס

התיעוד של API יכול להיות מסובך. בקשו מ-Claude עזרה בהבנה שלו:

אני לומד/ת אוטומציה עסקית ועובד/ת עם Postman.
הסבר לי בעברית פשוטה איך שולחים בקשה ל-endpoint של יצירת פוסט ב-JSONPlaceholder:
איזו שיטה, איזו כתובת, אילו כותרות ומה הגוף.
בסוף, תן לי פקודת curl מוכנה שאוכל לייבא ל-Postman.

ייבאו את פקודת ה-curl ל-Postman (דרך Import ‹ Raw text) והריצו אותה.
