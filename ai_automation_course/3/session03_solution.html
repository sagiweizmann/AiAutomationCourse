{
  "name": "נועה",
  "vip": true,

שלוש שגיאות: name בלי מירכאות, True באות גדולה (צריך true), וגרשים במקום מירכאות כפולות.

רוב השגיאות ב-JSON הן פסיקים ומירכאות. כש-Make מחזיר "Invalid JSON", מתחילים לבדוק משם.

POST, כותרות ושגיאות

חלק א': קוד 201 Created. בתשובה הופיע שדה חדש, "id": 101: המזהה שהשרת נתן לרשומה החדשה. (JSONPlaceholder לא שומר את הרשומה באמת, הוא רק מדמה יצירה.)

חלק ב': httpbin החזיר את הגוף תחת json, ואת הכותרות תחת headers, כולל X-Api-Key. כך רואים בדיוק מה המערכת שלכם שלחה. זה כלי מצוין לאיתור תקלות.

Webhook

ב-webhook.site כל ליד הופיע מיד, עם שעה מדויקת, כותרות (כמו content-type: application/json) והגוף המלא.

ההבדל מ-Polling: ב-Webhook המערכת השולחת "דוחפת" את המידע ברגע שהאירוע קורה. אין המתנה ואין בקשות ריקות. ב-Polling המערכת שלנו שואלת שוב ושוב, ולכן יש עיכוב ובזבוז של פעולות.

לשלוח GET במקום POST, או לשכוח לבחור JSON בלשונית Body. אז הבקשה מגיעה בלי גוף, או עם גוף בפורמט טקסט רגיל.

קריאה ל-Claude API

תשובה אופיינית (המספרים והמזהה יהיו שונים אצלכם):

{
  "id": "msg_01...",
  "type": "message",
  "role": "assistant",
  "model": "claude-sonnet-5-5",
  "content": [
    {
      "type": "text",
      "text": "{\"customer_name\": \"רונית שגב\", \"order_id\": \"50912\", \"topic\": \"delivery\", \"urgency\": \"high\"}"
    }
  ],
  "stop_reason": "end_turn",
  "usage": { "input_tokens": 150, "output_tokens": 40 }
}
  1. (א) הנתיב: content[0].text. שימו לב שהערך הוא מחרוזת שמכילה JSON. ב-Make נפרק אותה עם מודול Parse JSON.
  2. (ב) ב-usage.input_tokens וב-usage.output_tokens. ההוראות (system) נספרות כחלק מהקלט בכל קריאה, ולכן כדאי שיהיו ממוקדות.
  3. (ג) המבנה נשאר זהה: אותם ארבעה שדות. הערכים משתנים, כאן topic: defect. בזכות העקביות הזו אפשר לבנות על Claude אוטומציה.
Claude מחזיר את ה-JSON עטוף ב-```json, או עם משפט פתיחה. פותרים את זה בהוראה חד-משמעית ב-system ("JSON בלבד, ללא ``` וללא טקסט נוסף"), ובמפגשים הבאים נראה גם דרכים מובנות לקבל פלט תקין.
401 למרות שהמפתח נכון: ה-Environment לא נבחר, או שיש רווח מיותר בתחילת המפתח או בסופו.

curl מוכן לייבוא

curl https://jsonplaceholder.typicode.com/posts \
  -X POST \
  -H "Content-Type: application/json" \
  -d '{"title": "ליד חדש", "body": "שולחן אלון", "userId": 1}'
curl הוא "השפה המשותפת" של התיעוד. כמעט בכל תיעוד של API יש דוגמאות curl, ואפשר לייבא כל אחת מהן ל-Postman בלחיצה, או להדביק אותה ב-Make במודול HTTP (Import cURL).
