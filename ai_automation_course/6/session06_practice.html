תרחיש קליטת חשבוניות

⏱ 30 דקותמאתגר
Drive · Watch Files→Drive · Download→HTTP → Claude→Parse JSON
  1. ב-Google Drive צרו תיקייה בשם "חשבוניות ספקים". בגיליון צרו לשונית "חשבוניות" עם העמודות: ספק, ח.פ., מספר, תאריך, לפני מע"מ, מע"מ, סה"כ, סטטוס, הערה, קישור.
  2. צרו תרחיש חדש עם Google Drive ‹ Watch Files in a Folder על התיקייה, ואחריו Google Drive ‹ Download a File.
  3. הוסיפו HTTP ‹ Make a request: שיטה POST, הכתובת https://api.anthropic.com/v1/messages, ושלוש הכותרות ממפגש 3. ב-Body type בחרו Raw, ב-Content type בחרו JSON, ובגוף הדביקו את ה-JSON שבהמשך. במקום 2.data מפו את השדה Data של הקובץ שהורד.
  4. סמנו Parse response: Yes, ואחר כך הוסיפו JSON ‹ Parse JSON על content[1].text. (ב-Make הספירה במערך מתחילה מ-1.)
  5. העלו את חשבונית 1 לתיקייה, והריצו (Run once).

בדיקות ונתב החלטות

⏱ 30 דקותמאתגר
  1. אחרי Parse JSON הוסיפו Tools ‹ Set multiple variables עם שלושה משתנים:
    • sum_ok = האם abs(subtotal + vat − total) < 0.01
    • vat_ok = האם abs(subtotal × 0.18 − vat) < 0.01
    • has_fields = האם יש ערך גם ב-invoice_number וגם ב-date
  2. הוסיפו Google Sheets ‹ Search Rows בלשונית "חשבוניות", עם התנאי: מספר = invoice_number וגם ח.פ. = supplier_id. המטרה היא לזהות חשבונית כפולה.
  3. הכניסו Router עם 4 מסלולים:
    • ① כפולה (Search Rows מצא תוצאה) ‹ מייל לנציג, בלי שורה חדשה.
    • ② לא עברה בדיקה (sum_ok, vat_ok או has_fields שווים false) ‹ שורה עם סטטוס "לבדיקה" והערה שמסבירה מה נכשל.
    • ③ עברה, ו-total > 5,000 ‹ שורה עם סטטוס "ממתין לאישור מנהלת" + מייל למיכל.
    • ④ Fallback ‹ שורה עם סטטוס "מאושר לתשלום".
  4. העלו את שלוש החשבוניות, אחת אחרי השנייה, ובדקו שכל אחת הגיעה למסלול הנכון.
איך כותבים "וגם" ו"או" במסנניםבמסנן של Make, תנאים באותה קבוצה מתחברים ב-AND. ה-OR יוצר קבוצה חדשה של תנאים. למסלול ②: שלוש קבוצות, ובכל אחת תנאי אחד (sum_ok = false · OR · vat_ok = false · OR · has_fields = false).
טבלה: חשבונית · המסלול שהגיעה אליו · הסטטוס בגיליון

אישור טיוטות דרך הגיליון

⏱ 25 דקותבינוני
תרחיש A (מפגש 5): … ← Sheets, status = ממתין→נציג משנה ל"מאושר"→תרחיש B: Search Rows ← Gmail ← Update Row
  1. בתרחיש "לידים חכמים" ממפגש 5, ודאו שכל שורה נשמרת עם status = "ממתין לאישור". הוסיפו לגיליון גם את העמודות "טיוטה מקורית" ו"נשלח בפועל".
  2. צרו תרחיש B בשם "שליחת טיוטות מאושרות". הטריגר: Google Sheets ‹ Search Rows עם התנאי status = "מאושר". בהגדרות התזמון בחרו Every 15 minutes.
  3. אחרי החיפוש הוסיפו Gmail ‹ Send an email למייל של הליד. גוף ההודעה הוא עמודת "טיוטת תשובה", כולל התיקונים של הנציג.
  4. אחר כך Google Sheets ‹ Update a Row: status = "נשלח", "נשלח בפועל" = הטקסט שנשלח, ותאריך השליחה = now.
  5. נסו: אשרו שורה אחת בלי שינוי, ושורה שנייה אחרי תיקון בטקסט. הריצו את תרחיש B.
כדי שלא יישלח פעמייםתרחיש B חייב לעדכן את הסטטוס ל"נשלח" מיד אחרי השליחה. אחרת, בהרצה הבאה הוא ימצא את אותה שורה וישלח אותה שוב.

אישור בלחיצה מהמייל

⏱ 20 דקותמאתגר
  1. צרו תרחיש C עם Custom webhook בשם "approve". העתיקו את הכתובת.
  2. בתרחיש A הוסיפו מייל לנציג עם הסיכום, הטיוטה ושני קישורים:
    {{כתובת ה-webhook}}?row={{מספר השורה}}&action=approve&token=bv-2026-secret
    …&action=reject&token=bv-2026-secret
  3. בתרחיש C: מסנן token = bv-2026-secret, ואחריו Sheets ‹ Get a Range Values (או Search Rows) כדי להביא את השורה, ו-Router:
    • approve, והסטטוס עדיין "ממתין לאישור" ‹ Gmail שולח ‹ Update Row עם status = "נשלח"
    • reject ‹ Update Row עם status = "נדחה" + משימה לנציג
  4. הוסיפו Webhook response שמחזיר לדפדפן "✓ נשלח", כדי שהנציג יראה שהלחיצה עבדה.
  5. לחצו פעמיים על אותו קישור. מה קורה בלחיצה השנייה?
