# בית ועיצוב · אתר הדגמה ל-weizmann.ai

אתר של חנות רהיטים פיקטיבית, עם טופס "צור קשר" ומסד נתונים של לידים שאפשר למשוך דרך API. בלי שרת ובלי Apps Script: הכול קבצים סטטיים.

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `index.html` | האתר: מוצרים, טופס צור קשר, "הלידים שנכנסו לאתר" (כל הלידים עם חיפוש, סינון לפי מקור ומספרים), וכתובות ה-API |
| `api/v1/leads/page-1.json` … `page-4.json` | ה-API: 32 לידים, 10 בכל עמוד |
| `api/v1/leads/L-1001.json` … | ליד בודד לפי מזהה |
| `api/v1/products.json` | קטלוג המוצרים: מחיר ומלאי |
| `gen.py` | יוצר מחדש את כל קובצי ה-API. עורכים את הלידים או המוצרים שם ומריצים `python3 gen.py` |

## איך מעלים ל-weizmann.ai

מעתיקים את כל התיקייה (`index.html` ו-`api/`) לתיקייה באתר, למשל `demo/`. אחרי זה:

- האתר: `https://weizmann.ai/demo/`
- ה-API: `https://weizmann.ai/demo/api/v1/leads/page-1.json`

`gen.py` ו-`README.md` לא חייבים לעלות. העמוד מסומן `noindex`, כך שגוגל לא יציג אותו.

## איך התלמידים משתמשים בזה

**1. הטופס שולח ל-Make שלהם (Webhook).**
פותחים את "⚙️ לתלמידים: לאן הטופס שולח?" בתחתית הטופס, מדביקים את כתובת ה-Custom webhook שלהם ושומרים. הכתובת נשמרת רק בדפדפן שלהם, כך שכל תלמיד מקבל את הלידים שהוא עצמו מזין. השדות מגיעים כטופס רגיל: `name`, `email`, `phone`, `product`, `budget`, `source`, `message`, `created_at`.

**2. משיכת לידים קיימים (API).**
ב-Make: `HTTP · Make a request`, Method `GET`, הכתובת של `page-1.json`, Parse response = Yes. ואז:
- `Iterator` על `leads` מפרק לליד-ליד.
- סיבוך: `has_more` ו-`next_page` אומרים שיש עוד עמודים. אפשר `Repeater` עם מספר העמודים, ובכתובת `page-{{i}}.json`.
- `products.json` משמש כקטלוג: נותנים אותו ל-AI כדי שיציע מוצר מתאים, עם מחיר ומלאי אמיתיים.
