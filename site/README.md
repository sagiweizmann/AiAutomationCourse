# אתר התלמידים של הקורס

התיקייה הזאת היא אתר סטטי מלא. אפשר להעלות אותה כמו שהיא לכל שרת אינטרנט או שירות אחסון סטטי, ואפשר גם לפתוח אותה ישירות מהמחשב.

## מה יש בתיקייה

- `index.html`: דף הבית של הקורס. ממנו נכנסים לכל מפגש. **זו נקודת הכניסה.**
- `session01/index.html`: התרגילים של מפגש 1, כולל ההכנה (חשבון Claude ו-Claude Desktop) והמשימות לבית.
- `session01/summary.html`: דף הסיכום של מפגש 1.
- `session01/glossary.html`: מילון המושגים של מפגש 1.
- `session01/data/policy.txt`: מסמך המדיניות של "בית ועיצוב", לתרגיל 6.
- `assets/`: העיצוב והקוד המשותפים לכל הדפים.

## איך מעלים

1. מעתיקים את **כל** התיקייה `site` לשרת, כולל כל תתי-התיקיות. כל הקישורים יחסיים, אז אפשר לשים אותה בכל נתיב.
2. כתובת האתר היא הכתובת של `index.html` שבתיקייה.
3. אין צורך בשרת מיוחד, במסד נתונים או בהתקנה. הגופנים נטענים מ-Google Fonts, וכל השאר נמצא בתיקייה.

### אפשרות חינמית: GitHub Pages

המאגר כבר נמצא ב-GitHub, אז אפשר לפרסם את האתר בחינם:

GitHub Pages מפרסם רק מהשורש של המאגר או מתיקייה בשם `docs`, אז הדרך הפשוטה:

1. מעתיקים את תוכן התיקייה `site` לתיקייה חדשה בשם `docs` בשורש המאגר, ומעלים (commit ו-push).
2. ב-GitHub, בהגדרות המאגר: **Settings › Pages**. תחת **Build and deployment** בוחרים **Deploy from a branch**, את הענף הראשי ואת התיקייה `/docs`.
3. אחרי דקה או שתיים האתר זמין בכתובת ש-GitHub מציג באותו מסך.

## חשוב

- **לא להעלות לכאן את המצגת** (`session01_slides.html`): היא כוללת את הפתרונות למדריך.
- התיבות "סיימתי" נשמרות בדפדפן של כל תלמיד בלבד, ולא נשלחות לשום מקום.
- כשמוסיפים מפגש: יוצרים תיקייה `session02/` באותו מבנה, ומעדכנים את הכרטיס שלו ב-`index.html`.
