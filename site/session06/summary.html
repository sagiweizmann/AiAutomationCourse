בדיקה עצמית

6 שאלות: מה נשאר לכם מהמפגש?

1. עשיתם Regenerate לטוקן ב-monday. מה צריך לעשות ב-Make?
הסבר: הטוקן שמור בחיבור, לא במודולים. מעדכנים במקום אחד, וכל התרחישים שמשתמשים בחיבור ממשיכים לעבוד.
2. מה המשמעות של הבועה 5. Urgency?
הסבר: המספר הוא מזהה המודול, שניתן לפי סדר היצירה. אצלנו Parse JSON הוא 5, כי מחקנו והוספנו מודולים.
3. איזה שדה חייב Map בתרחיש הלידים?
הסבר: בכל ריצה זה ליד אחר. אם בוחרים ליד מרשימה — כל הלידים ייכתבו על אותה שורה.
4. Parse JSON עבר, אבל Topic ריק. Haiku החזיר {"Topic": "מחיר", …}. למה?
הסבר: Parse JSON מחפש מפתח בשם המדויק. אות גדולה = מפתח אחר. לכן כותבים בפרומפט את שמות המפתחות בדיוק.
5. Run once, ו-"The module didn't return any new data", למרות שיש 5 לידים בלוח. מה הסיבה הסבירה?
הסבר: הטריגר זוכר איפה עצר. לידים שכבר עברו בו (גם בריצה שנעצרה) לא יחזרו. Choose where to start מזיז את הסימנייה.
6. בכיתה, Gmail נכשל: Missing value of required parameter 'to'. מה התיקון הכי שלם?
הסבר: המיפוי הנכון מטפל בלידים עם אימייל. ה-Router מטפל בלידים בלי — במקום שגיאה, הנציג מקבל הערה בלוח.
