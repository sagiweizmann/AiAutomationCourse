⏱ 10 דקותבינוניבכיתה

  1. לפני שמתחילים — תחזית: אם Item ID יהיה תמיד "נועה ברק", מה יקרה כשליד חדש ייכנס? כתבו משפט

  5. פותחים את הלוח: את מי עדכן Haiku? מה כתוב אצל נועה עכשיו?
  6. מחזירים: Item ID ← Map דולק ← הבועה ID מהטריגר ← Save

מעבדת JSON: שוברים בכוונה

⏱ 10 דקותבינוניבכיתה

לראות מה Parse JSON עושה עם JSON תקין, שבור, ועם מפתח בשם לא נכון.

  1. בעותק: קליק ימני על Parse JSON ← Run this module only
  2. בחלון שנפתח, ב-JSON string, מדביקים את ניסוי א׳ ← OK. מה יצא?
  3. שוב, עם ניסוי ב׳ (עטוף ב-```). מה ההודעה?
  4. שוב, עם ניסוי ג׳ (Topic באות גדולה). איזה שדה יצא ריק?

ליד בלי אימייל לא מפיל את הריצה

⏱ 20 דקותבינוני📝 לבית

התיקון לשגיאה מהכיתה: לפני Gmail, Router שבודק אם יש אימייל. יש — טיוטה. אין — הערה בלוח "חסר אימייל".

  1. בתרחיש מתרגיל 5: קליק ימני על החיבור בין מודול 4 ל-Gmail ← Add a router
  2. מסלול 1 ← הקו ← Set up a filter ← שם: "יש אימייל" ← Condition: אימייל › Email ← Exists (Basic operators) ← המשך ל-Gmail ול-Create an Update
  3. מסלול 2 ← Fallback route = Yes ← monday.com · Create an Update ← Body: "⚠️ חסר אימייל — Haiku ניתח, אבל לא נוצרה טיוטה. סיכום: [Summary]"
  4. Choose manually ← הליד שלפני מיכל לב ← Run once

איך יודעים שעשיתם טוב

  • מיכל עברה במסלול 2, וקיבלה הערה "חסר אימייל"
  • ליד עם אימייל עדיין מקבל טיוטה
