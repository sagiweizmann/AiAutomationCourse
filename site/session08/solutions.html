הפילטר "חדש": אם אצלכם Search Rows עוצר כשהוא לא מוצא כלום, אפשר להחליף אותו ב-Google Sheets · Search Rows (Advanced) או לשים Array aggregator אחריו ולבדוק length(Array) = 0. בדקו בפלט מה קורה בליד חדש לפני שבונים את הפילטר.

Fallback: ב-Router, לוחצים על הקו ← Set up a filter ← Fallback route: Yes. הוא רץ רק כשאף מסלול אחר לא התאים.
