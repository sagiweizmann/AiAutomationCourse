איך בוחרים

עץ החלטה: איך מחברים את האפליקציה הזו?

  1. יש לה מודול ב-Make, עם הפעולה שאני צריך? ← מודול מוכן
  2. יש מודול, אבל לא לפעולה? ← Make an API call
  3. אין מודול, אבל יש API מתועד? ← HTTP
  4. צריך שהאפליקציה תודיע מיד כשמשהו קורה? ← Webhook (אם היא תומכת)
  5. אין API בכלל? ← עקיפה: מייל אוטומטי (Email parser), ייצוא לגיליון, או בקשה מהספק
  • תרגיל בכיתה: כל אחד אומר אפליקציה מהעבודה, והכיתה עונה באיזו דרך.

  • אותו עיקרון עובד עם Slack, Discord, Teams — רק מודול אחר.

📖 מה כתוב בתיעוד של Telegram
sendMessage
Use this method to send text messages.
Parameters:
  chat_id   Integer or String   Required
  text      String              Required
  parse_mode String             Optional
🧭 מה זה אומר לנו
• Method: POST (שולחים)
• URL: …/bot<TOKEN>/sendMessage
• חובה: chat_id, text
