1

פותחים בוט

✅ מה צריך להיות לכםבוט עם שם משתמש שנגמר ב-bot, טוקן בצורה 1234567890:AAH… (מספר, נקודתיים, מחרוזת), ושיחה פתוחה עם הבוט שבה שלחתם /start.

BotFather אומר "Sorry, this username is already taken"? הוסיפו מספר או שם משלכם. שם התצוגה יכול להיות בעברית, שם המשתמש — רק אנגלית, ספרות וקו תחתון.

למה דרך 2? אין מודול "תן לי עדכונים כרשימה", אבל יש פעולה ב-API. Make an API call משתמש בחיבור הקיים — לא מדביקים את הטוקן בשום שדה.

הליד של אורי (ציון 9) שולח הודעה. נועה (7) — לא. אם שום ליד לא שולח: בדקו שהאופרטור הוא Numeric (Greater than or equal to) ולא Text, אחרת "9" ו-"8" מושווים כמחרוזות.

✅ מבנהCustom webhook ← monday Create an Item ← (בונוס) Webhook response

ההבדל מ-Watch Board's Items: שם Make שואל את monday כל 15 דקות. כאן מישהו מבחוץ שולח ל-Make, והתרחיש רץ מיד — ובלי לשלם על בדיקות ריקות.

6

השרשרת המלאה

✅ מה צריך לקרות לאבינוצר בלוח (תרגיל 5) ← Haiku: דחיפות גבוהה, ציון 8–9 (תאריך קרוב + איום במתחרה) ← טיוטה ב-Gmail ← הודעה בטלפון (תרגיל 3).

שלושה דפוסים בשרשרת אחת: סנכרון (טופס ← monday), העשרה (Haiku), ניתוב + התראה (Router ← Telegram), ואישור (טיוטה).
